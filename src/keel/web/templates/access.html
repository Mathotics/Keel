Roles and permissions

A role includes the permissions in its row. Owner bypasses every check instead of holding a list. Editor includes the day-to-day permissions for issues, schedules, sprints, and comments. Custom includes none, so that person's access is only the permissions granted to them. No Access includes none and clears the permissions already granted to that person. A global create, edit, delete, or comment permission is required for that action and does not grant it in every project. A direct grant uses the same permissions.
